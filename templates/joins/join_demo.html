Why the extra row appears

The WHERE clause filters only the fictional user accounts. A condition such as WHERE a.status = 'Scheduled' would discard Carlo's NULL row. To retain all patients while matching only scheduled appointments, place that condition in ON.

04 / HOW THE QUERY RUNS

Parameters & table names

Both statements use the same six parameter values, in this order:

    {% for value in query_params %}
  1. {{ value }}
    2. {% endfor %}

Django passes these values separately with cursor.execute(sql, params). The %s placeholders are unquoted. The statements above are the actual raw SQL used, rather than SQL guessed from an ORM filter.

Both examples use INNER JOIN "user" to retrieve names because every patient has a required user. The join being compared is Patient → Appointment. TeknoCare declares the table names patient, appointment, and user explicitly. Double quotes distinguish the "user" table from PostgreSQL's USER keyword.
